Data dan logika konten terstruktur untuk Website Kedai Kopi Irama Santri.

== Description ==

Plugin ini menyediakan:

* CPT `product` dan taxonomy `product_category`.
* Meta harga, varian, add-on, ketersediaan, dan featured.
* CPT `facility` untuk fasilitas kedai.
* Public read API untuk Theme.
* Pengaturan info kedai dan pemetaan halaman.

Plugin tidak mengatur desain visual. Theme bertanggung jawab atas presentasi.

== Installation ==

1. Aktifkan plugin melalui menu Plugins.
2. Buka menu Irama Santri untuk mengatur info kedai.
3. Tambah produk melalui menu Produk.
4. Tambah fasilitas melalui menu Fasilitas.
